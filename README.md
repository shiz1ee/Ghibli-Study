## Study Cabin

A cozy study timer and to-do list. it's a remake of Ghibli Study by Remy.

[Demo]()

## What I changed

I split it into html, css and javascript, redid the look and added a bunch of stuff! 

# Timer 

- The timer doesn't just stop at 0. iit keeps going as overtime until you press "stop and break".
- An Arch fills up gradually as teh time passes, its orange while u focus and turns green at overtime.
- The break starts by itself after u stop, and u can also pick 5, 10, and 15 minutes.
- every 4th session gives you a 15 minute long break as staying that long without a long break can cause headaches and eyesores.
- sounds: a sharp buzz when focus hits 0, and a soft chime when u start your break.

# Tasks 

- Tasks save in localStorage, so they're still there after a refresh.
- Double-click a task to edit it and grab it to move it up or down.
- Priority (low/medium/high) and due dates. late tasks get an overdue tag.


# Look and feel 
- New forest color paletter with a light and dark mode.
- blurred background image instead of static white.
- draggable STICKERS with a thin black outline. they remember where you left them.
- custom favicon
- I still wanted to keep the original Ghibli theme so i added these stickers and the background.

## Tech stack

- HTML, CSS, vanilla JavaScript
- localStorage 
- Fonts: IBM Plex Sans and source Serif 4 from google fonts.

# Running it
No install needed. Download or clone the repo and open ```index.html``` in a browser. if u are using vscode then live server extension works too

```
git clone https://github.com/shiz1ee/Ghibli-Study.git
```
